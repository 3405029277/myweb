# 阶乘逆元学习笔记

---

## 1. 核心概念

### 1.1 逆元

模运算下的**倒数**，满足：
 $x \times inv(x) \equiv 1 \pmod{mod}$ 
作用：把模运算中的**除法**转化为**乘法**，解决模运算不能直接做除法的问题。

### 1.2 阶乘逆元

阶乘的逆元，即：
 $inv_fact[i] = inv(i!) = (i!)^{mod-2} \pmod{mod}$ 
作用：**O (1) 快速计算排列数、组合数**，替代暴力循环，大幅提升大数据下的效率。

---

## 2. 使用条件

> ⚠️ 这套模板**不是通用的**，必须满足以下条件才能用：
> 
> 

1. **模数 ** **`mod`** ** 必须是质数**

    - 比如竞赛常用的 `998244353`、`1e9+7`，都是质数，这是费马小定理的前提

2. 待处理的数 `x` 必须满足 `x < mod`，且与 `mod` 互质

    - 质数模下，只要 `x` 不是 `mod` 的倍数，就天然满足

3. 预处理的最大 `n` 不能超过 `mod`

    - 因为当 `n >= mod` 时，`n!` 会包含 `mod` 这个因子，模 `mod` 后为 0，逆元不存在

---

## 3. 原理推导

### 3.1 逆元的计算：费马小定理

如果 `mod` 是质数，那么对任意 `a` 满足：
 $a^{mod-1} \equiv 1 \pmod{mod}$ 
两边同时除以 `a`，得到逆元公式：
 $inv(a) = a^{mod-2} \pmod{mod}$ 

### 3.2 阶乘逆元的递推

我们可以先算出最大的 `inv_fact[n]`，然后倒推前面的：
因为：
 $i! \times (i+1) = (i+1)!$ 
两边取逆元：
 $inv(i!) = inv((i+1)!) \times (i+1) \pmod{mod}$ 
这样就可以从后往前 O (n) 递推，不用每个阶乘都算一次快速幂，效率极高。

## 4. 完整代码模板（带详细注释）

```cpp

#include <iostream>
#include <string>
using namespace std;

// 常用模数，可根据题目修改
const long long mod = 998244353;
// 最大n，根据题目数据范围调整，比如n<=2e5就开2e5+10
const int MAXN = 200010;

// 阶乘数组：fact[i] = i! % mod
long long fact[MAXN];
// 阶乘逆元数组：inv_fact[i] = inv(i!) % mod
long long inv_fact[MAXN];

/**
 * 快速幂：计算 a^b % mod
 * 用来求逆元，把复杂度从O(mod)降到O(log mod)
 */
long long pow_mod(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        // 如果b是奇数，把当前a乘到结果里
        if (b & 1) {
            res = res * a % mod;
        }
        // a平方，b折半
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

/**
 * 预处理：阶乘 + 阶乘的逆元
 * 必须在使用前调用，传入题目中的最大n
 */
void init(int n) {
    // 1. 先算阶乘：从1到n，正序递推
    fact[0] = 1;
    for (int i = 1; i <= n; i++) {
        fact[i] = fact[i-1] * i % mod;
    }

    // 2. 先算最大的n的阶乘的逆元
    inv_fact[n] = pow_mod(fact[n], mod - 2);

    // 3. 倒推前面的阶乘逆元
    for (int i = n - 1; i >= 0; i--) {
        inv_fact[i] = inv_fact[i+1] * (i+1) % mod;
    }
}

/**
 * 计算排列数 A(n, k)
 * 从n个元素中选k个，按顺序排列的方案数
 * A(n,k) = n!/(n-k)!
 */
long long A(int n, int k) {
    // 边界判断：k不能大于n，否则方案数为0
    if (k < 0 || k > n) return 0;
    return fact[n] * inv_fact[n - k] % mod;
}

/**
 * 计算组合数 C(n, k)
 * 从n个元素中选k个，不考虑顺序的方案数
 * C(n,k) = n!/(k!*(n-k)!)
 */
long long C(int n, int k) {
    // 边界判断：k不能大于n，否则方案数为0
    if (k < 0 || k > n) return 0;
    return fact[n] * inv_fact[k] % mod * inv_fact[n - k] % mod;
}
```
