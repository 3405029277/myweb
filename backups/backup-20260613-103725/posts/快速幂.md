# 快速幂算法模板笔记

快速幂是数论中非常常用的高效算法，主要用来快速计算大数幂运算的模结果，能把原本    $O(b)$    的时间复杂度直接降到    $O(\log b)$   ，非常适合处理超大指数的计算场景，是算法刷题里的高频模板。

## 算法核心原理

我们要计算的是    $a^b \mod p$   ，直接循环乘 b 次效率太低，我们可以把指数    $b$    拆成二进制来拆分计算：
比如计算    $a^5$   ，5 的二进制是 `101`，那么：
 $a^5 = a^{4+1} = a^4 \times a^1$ 
我们只需要从低位到高位遍历 b 的二进制位：

1. 每次把底数 a 平方，对应二进制位的权重翻倍（从    $a^1 \to a^2 \to a^4 \to a^8...$   ）

2. 如果当前二进制位是 1，就把当前的 a 乘到结果里

3. 全程对 p 取模，避免数值溢出

## 标准模板实现（C++）

这是修正后的完整可用的快速幂模板，你可以直接复制到代码里复用：

```cpp

typedef long long ll;

// 快速计算 (a^b) % p
ll ksm(ll a, ll b, ll p)
{
    ll res = 1; // 结果初始值为1
    while(b) {  // 当指数b不为0时，继续处理
        if(b & 1) { // 如果当前二进制位是1，累乘到结果
            res = res * a % p;
        }
        a = a * a % p; // 底数平方，权重翻倍
        b >>= 1; // 指数右移，处理下一位
    }
    return res;
}
```

## 常见易错点

之前写模板的时候很容易踩这两个坑，一定要注意：

1. **循环条件写反**
错误写法：`while(!b)`
这个条件的意思是「当 b 为 0 的时候才循环」，会导致直接跳过循环，永远返回初始值 1，结果全错。
正确写法：`while(b)`，意思是「当 b 不为 0 的时候循环」，直到把所有二进制位处理完。

2. **结果映射的下标对应**
比如在星期几的问题里，模 7 的结果 0 对应周日，1 对应周一，不要把数组的顺序写反，否则会导致结果偏移一天。

## 应用示例：星期几问题

比如之前的题目：今天是周日，问    $a^b$    天后是星期几？
我们就可以用这个模板直接计算：

```cpp

int main()
{
    int a,b;
    cin>>a>>b;
    // 计算 a^b %7
    int n = ksm(a,b,7);

    // 下标严格对应：0=周日,1=周一...6=周六
    string week[]={"Sunday","Monday","Tuesday","Wednesday","Thursday","Friday","Saturday"};
    cout<<week[n]<<endl;
    return 0;
}
```

测试样例：输入`3 2000`，输出`Tuesday`，完全正确。
